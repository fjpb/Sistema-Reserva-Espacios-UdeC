================================================================================
PAQUETE DE DESPLIEGUE: TEMA INSTITUCIONAL UDEC PARA MRBS
Universidad de Concepción - Campus Los Ángeles
================================================================================

Este directorio contiene exclusivamente los archivos necesarios para activar el
nuevo diseño institucional UdeC, las Hover Cards, la Línea de Tiempo en Vivo,
el campo de Solicitante y el nuevo Panel Visual Web de Tipos y Colores.

--------------------------------------------------------------------------------
ESTRUCTURA DE ARCHIVOS Y DESTINO EN EL SERVIDOR:
--------------------------------------------------------------------------------
1. admin_pending.php            -> Copiar a /ruta-mrbs/admin_pending.php
   (Panel Web Administrativo de Reservas Pendientes y Sin Confirmar: permite
   filtrar, confirmar o rechazar en 1 clic reservas puntuales y series semestrales).

2. admin_types.php              -> Copiar a /ruta-mrbs/admin_types.php
   (Panel Web interactivo para Administradores: edición visual de nombres y
   colores institucionales de carreras con selector de color HTML5 en vivo).

3. Themes/udec/                 -> Copiar a /ruta-mrbs/Themes/udec/
   - custom.css                 (Estilos visuales UdeC, paneles admin y animaciones)
   - custom.js                  (Hover cards, filtro de horarios por tipo y hora actual)
   - header.inc                 (Cabecera UdeC, botones Pendientes con contador y Tipos)
   - styling.inc                (Paleta institucional y carga dinámica de tipos)
   - types_config.json          (Almacenamiento persistente de tipos y colores)

4. images/escudo-udec.png       -> Copiar a /ruta-mrbs/images/escudo-udec.png
   (Emblema institucional oficial)

5. functions_table.inc          -> Copiar a /ruta-mrbs/functions_table.inc
   (Enriquecimiento de datos y horarios exactos para Hover Cards y filtros)

6. css/mrbs.css.php             -> Copiar a /ruta-mrbs/css/mrbs.css.php
   (CSS base limpio sin bordes toscos antiguos)

7. config.inc.php               -> Copiar a /ruta-mrbs/config.inc.php
   (Carga dinámica de tipos desde JSON, campo Solicitante y tema 'udec')

8. actualizar_salas_udec.sql    -> Importar en phpMyAdmin / MySQL (Base de Datos)
   (Actualiza capacidades y equipamiento oficial de salas según planilla Excel,
   incorpora Laboratorio Música, Lab. de Artes, Lab. Geomática y el nuevo
   Edificio de Laboratorios con Lab 1, Lab 2 y Lab 3 sin alterar reservas históricas).

--------------------------------------------------------------------------------
IMPORTANTE RESPECTO A PERMISOS EN EL SERVIDOR:
--------------------------------------------------------------------------------
Asegúrate de que el archivo 'Themes/udec/types_config.json' tenga permisos de
escritura para el servidor web (Apache/PHP):
  chmod 666 /ruta-mrbs/Themes/udec/types_config.json
  (o chown www-data:www-data Themes/udec/types_config.json)
De esta forma, cuando un Administrador guarde cambios desde el navegador en
'Tipos y Colores', los cambios se guardarán automáticamente sin tocar código.

--------------------------------------------------------------------------------
BASE DE DATOS (Campo 'Solicitante' y Actualización de Salas/Espacios):
--------------------------------------------------------------------------------
1. Para habilitar el campo personalizado "Solicitante" en el formulario de reservas
   y las Hover Cards, ejecuta estas dos consultas SQL en phpMyAdmin o consola MySQL:

   ALTER TABLE mrbs_entry ADD COLUMN solicitante VARCHAR(150) NULL DEFAULT '';
   ALTER TABLE mrbs_repeat ADD COLUMN solicitante VARCHAR(150) NULL DEFAULT '';

2. Para actualizar las capacidades, equipamiento y nuevas salas del Campus Los Ángeles,
   importa el archivo incluido `actualizar_salas_udec.sql` desde la pestaña "Importar"
   o "SQL" de phpMyAdmin sobre la base de datos `unidadti`.

(Nota: Ambas operaciones son 100% seguras e idempotentes; no afectan ninguna de las
reservas históricas ya existentes).

--------------------------------------------------------------------------------
DESPUÉS DE SUBIR LOS ARCHIVOS:
--------------------------------------------------------------------------------
1. Inicia sesión en MRBS con tu usuario Administrador.
2. En la barra superior verás el nuevo botón "Tipos y Colores" con ícono de paleta.
3. Abre tu navegador y presiona:
   - En Mac:      Cmd + Shift + R
   - En Windows:  Ctrl + F5
Para limpiar la memoria caché y disfrutar del sistema actualizado.
